# vendas-api

Projeto criado com o objetivo de praticar e aplicar conceitos avançados de desenvolvimento backend, com foco em qualidade de código, organização e boas práticas.

## 🎯 Objetivos técnicos

- ✅ Aplicação de **Arquitetura Limpa (Clean Architecture)**
- ✅ Organização por camadas (domain, use-cases, infra, interfaces)
- ✅ **Tratamento global de erros** com middlewares
- ✅ **Validação de dados** com Zod/Yup
- ✅ Separação de responsabilidades
- ✅ Padronização de código com ESLint + Prettier
- ✅ Boas práticas com Git (commits semânticos)
- 🚧 Integração com testes unitários e de integração (em andamento)
- 🚧 CI/CD com GitHub Actions (em andamento)

## 🧱 Tecnologias utilizadas

- Node.js
- Express
- PostgreSQL
- Prisma
- Zod
- dotenv
- Docker (em breve)
